# OnlyAndey - Hostel Egg Delivery App

A responsive, lightweight web application for managing egg delivery orders in a hostel.

## Prerequisites
- Node.js (v18+)
- pnpm (or npm/yarn)

## Installation
1. Clone the repository
2. Install dependencies:
   \`\`\`bash
   pnpm install
   \`\`\`
3. Copy `.env.example` to `.env.local` and fill in your values:
   \`\`\`bash
   cp .env.example .env.local
   \`\`\`

## Development
Run the development server:
\`\`\`bash
pnpm dev
\`\`\`
The app will be available at [http://localhost:3000](http://localhost:3000).

## Admin Dashboard
Access the admin panel to view orders, change pricing, and toggle shop status at:
[http://localhost:3000/admin](http://localhost:3000/admin)
